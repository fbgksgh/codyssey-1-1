# codyssey-1-1
나를 소개하는 웹페이지 만들기 

## 1. 프로젝트 소개

HTML, CSS, JavaScript를 활용하여 나를 소개하는 반응형 웹페이지를 제작했습니다. 자기소개, 보유 기술, 프로젝트, 연락처 등을 확인할 수 있으며, 화면 크기에 따라 레이아웃이 변경되도록 구현했습니다.

## 2. 사용 기술

- HTML: 웹페이지 구조와 콘텐츠 작성
- CSS: 디자인, 반응형 레이아웃, 다크 모드 구현
- JavaScript: 사용자 이벤트 처리, 폼 검증, GitHub API 연동
- GitHub: 프로젝트 코드 관리 및 배포

## 3. 주요 구현 내용

### 3-1. 시맨틱 HTML

`header`, `nav`, `main`, `section`, `article`, `footer` 등의 태그를 사용하여 웹페이지의 구조를 구분했습니다. Hero, About, Skills, Projects, Contact 영역을 구성하고, 내비게이션 메뉴를 통해 각 영역으로 이동할 수 있도록 했습니다.

### 3-2. Flexbox와 Grid

Flexbox는 내비게이션의 로고와 메뉴를 가로로 배치하고 간격과 정렬을 쉽게 조절하기 위해 사용했습니다. Grid는 프로젝트 카드를 격자 형태로 배치하고 화면 크기에 따라 열의 개수가 변경되도록 하기 위해 사용했습니다.

### 3-3. CSS 디자인 및 반응형 레이아웃

CSS 변수를 사용하여 색상을 관리하고 다크 모드에 필요한 스타일을 설정했습니다. 미디어 쿼리를 활용하여 모바일과 데스크톱 화면에 맞게 레이아웃이 변경되도록 구현했으며, 버튼과 카드에는 호버 효과와 전환 효과를 적용했습니다.

### 3-4. JavaScript와 DOM 조작

`querySelector`와 `addEventListener`를 사용하여 HTML 요소를 선택하고 사용자 동작을 처리했습니다. `textContent`, `innerHTML`, `classList` 등을 활용하여 화면의 텍스트와 스타일을 변경했습니다.

### 3-5. ES6+ 문법과 배열 처리

화살표 함수, 템플릿 리터럴, 구조 분해 할당 등의 문법을 활용했습니다. `map()`을 사용하여 GitHub 저장소 데이터를 프로젝트 카드로 변환하고, 배열 데이터를 처리하도록 구현했습니다.

### 3-6. 사용자 상호작용

- 모바일 화면에서 햄버거 메뉴를 열고 닫을 수 있도록 구현했습니다.
- 내비게이션 메뉴를 통해 해당 영역으로 부드럽게 이동하도록 했습니다.
- 스크롤 위치에 따라 맨 위로 이동하는 버튼이 표시되도록 했습니다.
- 스크롤 위치에 따라 내비게이션 스타일이 변경되도록 했습니다.
- 다크 모드를 적용하고, `localStorage`를 사용하여 선택한 테마가 유지되도록 했습니다.
- `IntersectionObserver`를 사용하여 화면에 나타나는 영역을 감지하고 애니메이션을 적용했습니다.

### 3-7. 연락처 폼 검증

이름, 이메일, 문의 내용을 입력할 수 있는 폼을 만들었습니다. 필수 항목이 비어 있거나 이메일 형식이 올바르지 않은 경우 입력 항목 아래에 오류 메시지가 표시되도록 구현했습니다. `preventDefault()`를 사용하여 기본 제출 동작을 막고 입력 내용을 검증했습니다.

### 3-8. GitHub API 연동 및 비동기 처리

`fetch`와 `async/await`를 사용하여 GitHub API에서 저장소 목록을 가져오도록 구현했습니다. `try/catch`를 사용하여 오류를 처리했으며, 로딩 중, 데이터 조회 성공, 데이터 없음, 요청 실패 상황에 따라 서로 다른 메시지가 표시되도록 했습니다. 요청에 실패하면 다시 시도할 수 있는 버튼도 제공했습니다.

### 3-9. 상태 변화와 화면 업데이트

사용자의 동작이나 데이터 요청 결과에 따라 화면이 변경되도록 구현했습니다.

- 다크 모드: 테마 변경에 따라 화면 스타일이 바뀌고 선택한 테마가 저장됩니다.
- GitHub API: 요청 결과에 따라 로딩, 성공, 실패, 데이터 없음 상태를 화면에 표시합니다.
- 연락처 폼: 입력 내용에 따라 오류 메시지를 표시하거나 변경합니다.

### 3-10. 배포 및 문서화

GitHub를 이용하여 프로젝트 코드를 관리하고 GitHub Pages를 통해 웹페이지를 배포했습니다. README에 프로젝트 소개, 사용 기술, 주요 기능 및 구현 내용을 정리했습니다.
